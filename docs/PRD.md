# CLX 매뉴얼 자동생성기 MVP PRD

## 🎯 핵심 정보

**목적**: exBuilder6 프레임워크 기반 `.clx.js` 파일을 분석하여 사용자 매뉴얼(HTML/MD)을 자동 생성하는 도구
**사용자**: exBuilder6로 화면을 개발하는 1인 개발자 또는 소규모 개발팀

## 🚶 사용자 여정

```
1. 메인 페이지 (대시보드)
   ↓ 3개 기능 카드 중 선택

   [매뉴얼 생성] → 매뉴얼 생성 페이지
   [단어사전 관리] → 단어사전 관리 페이지
   [레이아웃 관리] → 레이아웃 관리 페이지

--- 매뉴얼 생성 플로우 ---

2. 매뉴얼 생성 페이지
   ↓ 파일 업로드 (단일/멀티/폴더)

3. 파일 트리 표시
   ↓ 분석할 파일 선택 (체크박스)

4. 생성 옵션 설정 (AI 모델, 출력 형식)
   ↓ "매뉴얼 생성" 버튼 클릭

   [단어사전에 존재] → Supabase에서 설명 가져옴
   [단어사전에 미존재] → AI 모델 호출 → Supabase에 INSERT
   ↓

5. 결과 페이지 (분석 결과 + 매뉴얼 미리보기)
   ↓ HTML 미리보기 / MD 보기 / 다운로드

6. 완료 → 메인 페이지 / 새 파일 업로드 / 단어사전 관리
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

|----|--------|------|-------------|------------|
| **F001** | CLX 파일 파싱 | .clx.js 파일을 11개 카테고리(화면개요, CRUD, 필수값, 그리드, 조건그룹, 인포그룹, 팝업, 탭페이지 등)로 정적 분석 | 핵심 가치 - 코드 분석 엔진 | 매뉴얼 생성 페이지, 결과 페이지 |

| **F003** | 파일 트리 관리 | 업로드된 파일의 계층 구조 표시, 체크박스로 분석 대상 선택 (전체/폴더/개별 선택) | 다수 파일 중 대상 선별 필수 | 매뉴얼 생성 페이지 |

| **F005** | HTML 매뉴얼 출력 | 스타일링된 독립형 HTML 파일 생성 및 실시간 미리보기 | 최종 산출물 - 사용자에게 전달되는 매뉴얼 | 결과 페이지 |

| **F007** | 단어사전 관리 | Supabase DB 기반 용어/설명 CRUD 관리 (검색, 추가, 수정, 삭제) | AI 호출 최소화 및 일관된 용어 설명 보장 | 단어사전 관리 페이지 |
| **F008** | 단어사전 연동 생성 | 매뉴얼 생성 시 Supabase 단어사전 우선 조회 → 미존재 시 AI 호출 후 자동 INSERT | 비용 절감 + 설명 일관성 | 매뉴얼 생성 페이지, 결과 페이지 |
| **F009** | 레이아웃 템플릿 관리 | 매뉴얼 출력 레이아웃(섹션 순서, 스타일, 포함/제외 항목)을 커스터마이징하고 저장 | 다양한 매뉴얼 형식 요구 대응 | 레이아웃 관리 페이지 |
