## 1. 서비스 개요

CLX 매뉴얼 자동생성기는 **exBuilder6 프레임워크** 기반으로 개발된 화면의 `.clx.js` 파일을 자동으로 분석하여 HTML 또는 Markdown 형식의 사용자 매뉴얼을 생성합니다.

**핵심 목적:** 반복적이고 시간이 많이 소요되는 매뉴얼 수동 작성 업무를 AI로 자동화하여 개발팀의 생산성을 향상시킵니다.

### 주요 기능

| 기능 | 설명 |
|---|---|
| **매뉴얼 자동 생성** | `.clx.js` 파일을 업로드하면 AI가 11개 항목(화면개요·CRUD·그리드·팝업 등)을 분석하여 매뉴얼을 자동 작성 |
| **단어사전** | 자주 사용하는 용어와 설명을 미리 등록하여 AI 호출 비용을 최소화하고 일관성 유지 |
| **레이아웃 관리** | 매뉴얼에 포함할 섹션을 선택하고 순서를 조정하여 커스터마이징 가능 |
| **다운로드** | 생성된 매뉴얼을 HTML 또는 Markdown 형식으로 개별 또는 ZIP 일괄 다운로드 |

### 사용 흐름

```
STEP 1 파일 업로드
  .clx.js 파일을 드래그앤드롭 또는 버튼으로 업로드

STEP 2 AI 설정
  API 키와 모델을 설정하거나 VS Code 프록시 모드 사용

STEP 3 매뉴얼 생성
  파일을 선택하고 생성 버튼 클릭, 진행률 실시간 확인

STEP 4 결과 다운로드
  분석 결과 확인 후 HTML 또는 Markdown으로 다운로드
```

## 2. 메인 화면 안내

서비스에 접속하면 메인 대시보드가 표시됩니다. 상단 히어로 섹션에서 서비스 소개와 주요 통계를 확인할 수 있으며, 하단의 3개 카드를 통해 각 기능으로 이동할 수 있습니다.

### 화면 구성

- **매뉴얼 생성 카드**: `.clx.js` 파일을 업로드하여 매뉴얼을 자동 생성합니다.
- **단어사전 관리 카드**: 자주 사용하는 용어를 미리 등록하여 AI 호출을 최소화합니다.
- **레이아웃 관리 카드**: 매뉴얼에 포함할 섹션과 순서를 커스터마이징합니다.

## 3. 매뉴얼 생성하기

### 3.1 파일 업로드

메인 화면에서 **매뉴얼 생성** 버튼을 클릭하면 생성 페이지(`/generate`)로 이동합니다.
좌측 업로드 영역에서 다음 3가지 방법으로 파일을 업로드할 수 있습니다.

| 방법 | 설명 |
|---|---|
| **단일 파일 선택** | `.clx.js` 확장자 파일 하나를 선택 |
| **다중 파일 선택** | 여러 `.clx.js` 파일을 동시에 선택 |
| **폴더 선택** | 폴더 내 모든 `.clx.js` 파일을 재귀적으로 탐색하여 일괄 업로드 |

> **파일 트리 패널:** 업로드된 파일은 폴더 계층 구조로 표시됩니다. 체크박스로 개별 파일 또는 폴더 단위로 선택할 수 있으며, 전체 선택/해제도 가능합니다.

### 3.2 AI 설정

우측 패널에서 AI 모드와 모델을 설정합니다. 설정값은 자동으로 저장되어 다음 접속 시에도 유지됩니다.

| 설정 항목 | 설명 |
|---|---|
| **GitHub Models API 모드** | GitHub Personal Access Token을 입력하여 직접 API 호출. API 비용이 발생할 수 있습니다. |
| **VS Code 프록시 모드** | VS Code Copilot의 프록시 서버(기본: `localhost:3100`)를 통해 API 호출. 별도 키 불필요. |
| **모델 선택** | `gpt-4o-mini` (기본, 빠르고 경제적), `gpt-4o` (고품질), `gpt-4-turbo` 등 선택 가능 |

### 3.3 생성 실행

1. 파일 트리에서 매뉴얼을 생성할 파일을 체크박스로 선택합니다.
2. 출력 형식을 선택합니다: **HTML**, **Markdown** 또는 둘 다.
3. 단어사전 사용 여부를 설정합니다 (등록된 용어를 우선 사용하여 비용 절감).
4. **매뉴얼 생성** 버튼을 클릭합니다.
5. 각 파일별 진행률이 실시간으로 표시되며, 완료 후 결과 페이지로 자동 이동합니다.

> **참고:** 파일이 선택되지 않은 경우 생성 버튼이 비활성화됩니다. 단어사전에 등록된 용어는 AI를 호출하지 않고 저장된 설명을 재사용하므로 비용이 절약됩니다.

## 4. 결과 확인 및 다운로드

생성이 완료되면 결과 페이지(`/result`)로 자동 이동합니다. 좌측 사이드바에서 분석한 파일을 선택하고, 우측 탭에서 결과를 확인합니다.

### 4.1 분석 결과 탭

기본으로 열리는 탭으로, CLX 파싱 결과를 **11개 카테고리 아코디언**으로 표시합니다. 각 항목을 클릭하면 세부 내용이 테이블 형식으로 펼쳐집니다.

| 카테고리 | 표시 내용 |
|---|---|
| **화면개요** | 시스템명, 부시스템, 프로그램명, 화면 설명 등 기본 정보 |
| **CRUD 작업** | 조회·등록·수정·삭제 버튼과 연결된 함수 목록 |
| **필수값** | 저장/실행 시 반드시 입력해야 하는 필드 목록 |
| **그리드** | 화면 내 그리드 컴포넌트의 컬럼 구성 정보 |
| **조건그룹** | 검색 조건 영역(conditionGroup)의 필드 구성 |
| **인포그룹** | 정보 표시 영역(infoGroup)의 항목 구성 |
| **팝업** | 화면에서 호출하는 팝업 목록과 파라미터 |
| **탭페이지** | 탭 컴포넌트별 화면 구성 정보 |
| **버튼** | 화면 내 모든 버튼과 연결 함수 |
| **스타일** | UDC 컴포넌트 및 커스텀 스타일 정보 |
| **주의사항** | AI가 분석한 주요 업무 규칙 및 주의점 |

> **화면 이미지 첨부:** 분석 결과 탭 상단의 이미지 업로드 영역에서 실제 화면 캡처 이미지를 첨부하면, 생성된 HTML 매뉴얼에 화면 이미지가 포함됩니다.

### 4.2 HTML 미리보기 탭

생성된 매뉴얼을 **실제 HTML로 렌더링**하여 최종 결과물을 확인하는 탭입니다. 다운로드 전에 매뉴얼이 어떻게 보일지 미리 확인할 수 있습니다.

- 레이아웃 관리에서 설정한 섹션 구성과 순서가 그대로 반영됩니다.
- 업로드한 화면 이미지가 매뉴얼 상단에 포함되어 표시됩니다.
- 다운로드할 HTML 파일과 동일한 내용이므로 최종 검토에 활용하세요.

### 4.3 Markdown 탭

매뉴얼을 **Markdown 형식의 텍스트**로 확인하는 탭입니다. Notion, GitHub, Confluence 등 Markdown을 지원하는 문서 시스템에 바로 붙여 넣어 활용할 수 있습니다.

- 코드블록 형태로 전체 Markdown 텍스트가 표시됩니다.
- 우측 상단 **복사 버튼**으로 클립보드에 바로 복사할 수 있습니다.
- 헤딩(`##`), 테이블, 리스트 등 표준 Markdown 문법을 사용합니다.

### 4.4 다운로드

상단 다운로드 바에서 생성된 매뉴얼 파일을 저장할 수 있습니다.

| 다운로드 방법 | 설명 |
|---|---|
| **HTML 다운로드** | 현재 선택된 파일의 매뉴얼을 `.html` 파일로 저장. 브라우저에서 바로 열 수 있는 독립 문서 형식 |
| **Markdown 다운로드** | 현재 선택된 파일의 매뉴얼을 `.md` 파일로 저장. 다양한 문서 시스템에서 활용 가능 |
| **ZIP 일괄 다운로드** | 분석된 모든 파일의 HTML과 Markdown을 하나의 ZIP으로 묶어 한 번에 다운로드 |

## 5. 단어사전 관리

단어사전에 용어와 설명을 미리 등록해 두면, 매뉴얼 생성 시 해당 용어가 등장할 때 AI를 호출하지 않고 등록된 설명을 재사용합니다. **API 비용 절감과 설명 일관성**에 효과적입니다.

### 주요 기능

| 기능 | 설명 |
|---|---|
| **용어 추가** | 용어명, 컨텍스트 타입, 설명을 입력하여 새 항목 등록 |
| **용어 수정** | 기존 항목의 설명을 업데이트 |
| **용어 삭제** | 불필요한 항목 제거 (확인 다이얼로그 표시) |
| **전체 초기화** | 모든 사전 데이터 일괄 삭제 |
| **카테고리 필터** | 컨텍스트 타입별로 항목 필터링 |
| **AI/수동 구분** | AI가 생성한 설명과 수동 입력 항목을 구분하여 표시 |

> **활용 팁:** 자주 등장하는 도메인 용어(예: 수강신청, 학적번호, 수납금액 등)를 미리 등록해두면 생성 시간이 단축되고 API 비용이 크게 줄어듭니다.

## 6. 레이아웃 관리

매뉴얼에 포함할 섹션과 순서를 커스터마이징합니다. 불필요한 섹션을 제외하거나 조직의 스타일에 맞게 순서를 변경할 수 있습니다.

### 주요 기능

| 기능 | 설명 |
|---|---|
| **섹션 포함/제외** | 매뉴얼에 포함할 항목을 체크박스로 선택 |
| **순서 변경** | 드래그앤드롭으로 섹션 순서 재배치 |
| **프리셋 저장** | 현재 레이아웃 설정을 이름 붙여 저장 |
| **프리셋 불러오기** | 저장된 레이아웃 프리셋을 불러와 적용 |

> **활용 팁:** 업무 유형별로 프리셋을 만들어두면(예: "조회 화면용", "입력 화면용") 매번 설정을 변경하지 않고 빠르게 전환할 수 있습니다.

### 지원 섹션 목록

| 섹션 | 설명 |
|---|---|
| 화면개요 | 화면의 목적과 주요 기능 요약 |
| CRUD 작업 | 조회·등록·수정·삭제 기능 설명 |
| 필수값 | 입력 시 필수 항목 목록 |
| 그리드 | 그리드 컬럼 구성 및 의미 |
| 조건그룹 | 검색 조건 영역 구성 |
| 인포그룹 | 정보 표시 영역 구성 |
| 팝업 | 연결된 팝업 화면 목록 |
| 탭페이지 | 탭별 화면 구성 정보 |
| 버튼 | 화면 내 버튼 기능 설명 |
| 스타일 | UDC 및 커스텀 스타일 정보 |
| 주의사항 | 주요 업무 규칙 및 주의점 |

## PDF 재생성 방법

스크린샷이 포함된 PDF 사용자 가이드를 재생성하려면:

1. 개발 서버를 실행합니다: `npm run dev`
2. 브라우저에서 매뉴얼 생성을 완료합니다 (결과가 localStorage에 자동 저장됨)
3. 스크립트를 실행합니다:

```bash
node scripts/generate-pdf-guide.mjs
```

출력 파일: `docs/user-guide.pdf`
