사용방법

학생등록관리 조회

Step1. 조회조건(학년도, 학기, 학생명)을 입력한다.

Step2. 화면 상단의 '조회' 버튼을 클릭한다.

학생등록관리 신규

Step1. 화면 상단의 '신규' 버튼을 클릭한다.

Step2. 필수 항목(학번, 학생명)을 입력한다.

학생등록관리 저장

Step1. 수정하고자 하는 자료를 입력 또는 선택한다.

Step2. 화면 상단의 '저장' 버튼을 클릭하여 저장처리를 진행한다.

📌 필수 입력항목: 학생명, 학번

⚠ 학생명을 입력하세요.

⚠ 학번을 입력하세요.

학생등록관리 삭제

Step1. 삭제하고자 하는 자료를 선택한다.

Step2. 화면 상단의 '삭제' 버튼을 클릭하여 삭제처리를 진행한다.

엑셀다운로드

Step1. '엑셀다운로드' 버튼을 클릭하여 현재 목록을 엑셀 파일로 내보낸다.
